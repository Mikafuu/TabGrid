## English

### Package refresh — October 27, 2026

- License TabGrid under MIT; include the project license and existing third-party notices in the ZIP.
- Filter older TabGrid installations from Recently closed, preserve last-opened highlights during Undo, and fix menu/dialog focus warnings.
- Strengthen glass window tints and remove full-width caption backgrounds without wallpaper.
- Fix toolbar capture timing and remove preview cleanup from the startup readiness path.
- Validate 295 automated tests and the extracted package on macOS. Windows CI checks are included; native Windows Chrome testing remains outstanding.


Text now keeps the selected theme's colors instead of changing with the wallpaper. This release also brings English, Simplified Chinese, and Japanese support and the accumulated preview, interaction, and tab-lifecycle fixes.

### Changes

- Restore fixed theme colors for headings, labels, cards, menus, and inputs. Remove wallpaper-based text sampling and color overrides.
- Add browser-language detection, a language setting, translated extension metadata, and Chinese and Japanese READMEs.
- Improve preview refresh scheduling, capture handling, and content-script cleanup after extension reloads.
- Refine drag-return and group-panel animations, Undo transitions, dropdown scrolling, search-history removal, mute controls, and shortcut labels.
- Add Undo for grouping and ungrouping, and keep status tips at the bottom left while Undo stays centered at the bottom.
- Reuse an existing TabGrid when opening from the toolbar. Leave restored duplicates open to prevent Chrome's close/restore loop.
- Add optional close-after-tab-selection, disabled by default, with session-only view restoration and protection while Undo is available.
- Accept custom-background image files up to 1 GB, resizing images before local storage.
- Provide a compact runtime ZIP with third-party license notices, excluding development fixtures and unused files.

### Known limits

Chrome still controls screenshot permissions for New Tab, internal pages, and other restricted pages. Opening the extension through its toolbar icon or Chrome shortcut may be necessary to grant capture access for the active page. TabGrid cannot selectively delete its entries from Chrome's Recently closed history.

## 简体中文

### 安装包更新 — 2026 年 10 月 27 日

- 项目采用 MIT 许可证，安装包保留项目许可证及第三方声明。
- 修复最近关闭列表中的旧版 TabGrid 条目、撤销后的高亮、菜单焦点警告、玻璃拟态窗口色调及标题背景。
- 改进截图等待时间和启动流程。295 项自动化测试及 macOS 安装包检查通过；Windows 原生 Chrome 测试尚未完成。


文字现在会保持所选主题的颜色，不再随壁纸变化。本版本还加入了英语、简体中文和日语支持，并包含此前积累的预览、交互及标签页生命周期修复。

### 更新内容

- 恢复标题、标签、卡片、菜单和输入框的固定主题颜色，移除基于壁纸的文字颜色采样及覆盖逻辑。
- 新增浏览器语言检测、语言设置、翻译后的扩展元数据，以及中文和日文 README。
- 改进预览刷新调度、截图处理，以及扩展重新加载后的内容脚本清理。
- 优化拖动回位和分组面板动画、撤销提示的过渡、下拉菜单滚动、搜索历史删除、静音控件和快捷键标签。
- 为分组和取消分组加入撤销支持；状态提示保留在左下角，撤销提示保持在底部中央。
- 从工具栏打开时复用已有的 TabGrid。恢复出来的重复页面保持打开，避免 Chrome 陷入关闭与恢复的循环。
- 新增可选的“选择标签页后关闭”设置，默认关闭；仅在当前浏览器会话内恢复视图，并在撤销仍可用时保持 TabGrid 打开。
- 支持最大 1 GB 的自定义背景图片，在保存到本地前缩小图片。
- 提供包含第三方许可声明的精简运行包，排除开发测试素材及未使用的文件。

### 已知限制

新标签页、Chrome 内部页面及其他受限页面的截图权限仍由 Chrome 控制。可能需要通过扩展的工具栏图标或 Chrome 快捷键打开 TabGrid，才能为当前页面授予截图访问权限。TabGrid 无法选择性地删除自己在 Chrome“最近关闭”历史中的记录。

## 日本語

### パッケージ更新 — 2026年10月27日

- MIT ライセンスを採用し、プロジェクトのライセンスと第三者の通知を ZIP に同梱しました。
- 最近閉じたタブに残る旧 TabGrid、元に戻す操作後の強調表示、メニューのフォーカス警告、ガラス表示のウィンドウ色と見出し背景を修正しました。
- 撮影の待機時間と起動処理を改善しました。295 件の自動テストと macOS のパッケージ検査を通過しました。Windows の実際の Chrome での検証は未実施です。


文字色は選択したテーマの色を維持し、壁紙に応じて変わらなくなりました。このリリースでは英語、簡体字中国語、日本語に対応し、これまでのプレビュー、操作、タブのライフサイクルに関する修正も含めています。

### 変更内容

- 見出し、ラベル、カード、メニュー、入力欄を固定のテーマ色に戻しました。壁紙からの文字色のサンプリングと上書きを削除しました。
- ブラウザーの言語検出、言語設定、翻訳済みの拡張機能メタデータ、中国語と日本語の README を追加しました。
- プレビューの更新スケジュール、撮影処理、拡張機能の再読み込み後のコンテンツスクリプトの後処理を改善しました。
- ドラッグ後の復帰とグループパネルのアニメーション、取り消し通知の切り替え、ドロップダウンのスクロール、検索履歴の削除、ミュート操作、ショートカットのラベルを調整しました。
- グループ化とグループ解除の取り消しに対応しました。状態の通知は左下、取り消し通知は下部中央に表示します。
- ツールバーから開く際は既存の TabGrid を再利用します。復元された重複ページは開いたままにし、Chrome で終了と復元を繰り返すループを防ぎます。
- タブ選択後に TabGrid を閉じるオプションを追加しました。初期設定では無効です。表示状態は現在のブラウザーセッション内でのみ復元し、取り消しが可能な間は TabGrid を閉じません。
- 最大 1 GB のカスタム背景画像に対応しました。ローカル保存前に画像を縮小します。
- 第三者のライセンス通知を含むコンパクトな実行用 ZIP を提供します。開発用のテスト素材や未使用ファイルは含みません。

### 既知の制限

新しいタブ、Chrome 内部ページ、その他の制限付きページの撮影権限は、引き続き Chrome が管理します。現在のページの撮影を許可するには、拡張機能のツールバーアイコンまたは Chrome のショートカットから TabGrid を開く必要がある場合があります。TabGrid は、Chrome の「最近閉じたタブ」の履歴から自身の項目だけを削除することはできません。

## Additional offline font choices

Downloaded from the authors' repositories for the Appearance settings. Each font
is bundled as an unmodified variable WOFF2 and served only from the extension.

- Outfit: https://github.com/Outfitio/Outfit-Fonts, `fonts/variable/Outfit[wght].woff2` (Outfit-OFL.txt).
- Plus Jakarta Sans: https://github.com/tokotype/PlusJakartaSans, `fonts/webfonts/PlusJakartaSans[wght].woff2` (PlusJakartaSans-OFL.txt).
- Newsreader: https://github.com/productiontype/Newsreader, `fonts/variable/woff2/Newsreader[opsz,wght].woff2` (Newsreader-OFL.txt).
- Geist Mono: https://github.com/vercel/geist-font, `fonts/GeistMono/webfonts/GeistMono[wght].woff2` (OFL.txt, shared with Geist).

System font uses the device's installed interface font. Proprietary fonts named
in design references are not redistributed or presented as installed choices.
